# All In

## Deploy
1. Create a private GitHub repo named All-In and push this folder.
2. In Vercel: Add New Project, import the repo, name it `all-in`.
3. Deploy. Every push redeploys.

## Files
- public/index.html: the app (single file, works offline)
- api/food.js: Canadian Nutrient File proxy
- vercel.json, package.json: project config
